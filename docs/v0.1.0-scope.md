# V0.1.0 版本范围定义

日期：2026-10-10。总体规划见 [project-plan.md](./project-plan.md)。

## 本版本 = 规划中的 M0–M4

**目标**：在自建测试站上，完整跑通两种模式的跨设备登录态共享全链路（单机双实例模拟双机）。

### 包含

- 仓库脚手架与开发栈（docker-compose：Postgres + MinIO）
- **test-site**（Go）：带登录态的测试站（cookie 三变体 / localStorage / whoami / 会话管理台 / 过期与 IP 风控模拟 / 指纹回显页）
- **server**（Go）：注册登录（E2E 密钥信封托管）、环境 CRUD、快照元数据 + S3 presign 直传直下、模式二租约状态机 + WebSocket 信令
- **desktop**（Electron + Vue3）：
  - 环境（多隔离 partition、代理绑定、homepage）
  - 数据面 L1：cookie + localStorage 结构化抽取/注入
  - 快照引擎：manifest + AES-256-GCM 加密信封（Argon2id→KEK→DEK→HKDF 每快照子密钥）、本地导出/导入
  - 模式一：基线快照上云，任何设备从基线克隆分支（关闭即弃）
  - 模式二：租约持有 / 被驱逐（自动抓取上传）/ 接管下载恢复 / 心跳与失联兜底

### 不包含（后续版本）

- M5 外挂指纹内核（fingerprint-chromium、CDP 数据面、25-surface 指纹配置）
- M6 内核补丁与全保真文件级快照（IndexedDB / Service Worker）
- 安装包分发（electron-builder）、自动更新、快照保留策略清理、审计日志、团队协作
- 真实站点适配（Google 受 DBSC 限制，见调研报告 4.3）

### 验收标准（对应规划 §7.3 测试矩阵）

| # | 场景 | V0.1.0 达成方式 |
|---|---|---|
| T1 | A 登录→基线上云→B 克隆已登录 | `pnpm e2e` 自动化 |
| T2 | 分支语义（B 注销不影响基线） | `pnpm e2e` 自动化 |
| T3 | 模式二接管（A 被驱逐、B 接管最新数据） | `pnpm e2e` 自动化（双 CloudClient+LeaseAgent 模拟双设备） |
| T4 | A 失联兜底（心跳超时→旧基线 stale） | 服务端单测 + 手工 |
| T5 | E2E（云端只见密文） | 服务端单测 + MinIO 控制台人工抽查 |
| T6 | 会话过期提示 | 手工 |
| T7 | IP 风控与代理绑定 | 手工（test-site bind-ip 开关） |
| T8 | 并发/幂等 | 服务端单测 |
