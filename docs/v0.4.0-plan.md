# V0.4.0 计划：原生内核、分发与生产硬化

> 日期：2026-10-17。前置：V0.3.0 已交付 L2 文件级快照（kernel 路径，无需补丁）；V0.3.1 zstd 压缩。
> 三条主线彼此独立，可并行推进。

## 1. 原生内核 + os_crypt 补丁（解锁 mac/win 原生 L2）

**背景**：当前 kernel 承载依赖 Docker（Intel mac 无法跑官方 arm64-only 的 mac 预编译产物）；
生产桌面用户需要原生内核。原生内核的 L2 漫游受阻于 os_crypt（mac Keychain / win DPAPI 绑定本机）。

**事实核查（2026-10-17）**：fingerprint-chromium 最新二进制 150.0.7871.186（当前内核）；
源码分支只到 **148.0.7778.215**（按其惯例，150 的源码等 151 发布后放出）。

**路线**：
1. **A1 补丁 PoC（用 148 源码）**：基于 ungoogled-chromium 构建体系（submodule 指向
   fingerprint-browser 补丁仓库）构建 mac x64/arm64；给 `components/os_crypt` 加
   `--os-crypt-key=<hex>` 注入每环境密钥（由我们 DEK 经 HKDF 派生，与快照密钥体系同构）；
   双机/双 profile 拷贝验证 Cookies 可解密（`apps/desktop/scripts/os-crypt-roaming-poc.mjs` 思路移植）。
   本机构建：Docker 内交叉或原生（约 100GB 磁盘 + 数小时）。
2. **A2 版本跟进**：150 源码放出后重放补丁；产品内 kernelManager 增加「自建内核」渠道。
3. **A3 L2 全平台**：原生内核走与 Docker 相同的 L2 管线（挂载直通改为本机目录），
   kernelTag 用构建版本标识。

**出口标准**：mac 原生内核：指纹生效（T9 同款断言）+ L2 profile 漫游 PoC 通过 + os_crypt 密钥
经 DEK 派生（拿走 profile 目录无用户主密码不可解）。

## 2. builtin 承载 L2 化评估（结论：不做）

- Electron partition 的 Cookies DB 由 **Electron 的 os_crypt** 加密（mac 走 Electron 应用名下的
  Keychain 条目、win 走 DPAPI）——跨设备不可解，且与 Electron 版本/应用签名耦合，补丁面在
  Electron 侧不可控。
- 产品语义已闭环：kernel 环境双写（L2 + L1 副本），builtin 设备打开 L2 基线自动回退 L1
  （V0.3.0 实测 T-L2.3）。builtin 保持 L1 是正确终态，而非临时妥协。
- 唯一残余差距：builtin 设备上的 IndexedDB/SW 不随基线走——由「换 kernel 承载」解决
  （UI 已支持切换 hosting）。

## 3. 安装包分发

- `electron-builder`：mac dmg（x64+arm64）、win nsis x64、linux AppImage；图标与签名（mac
  Developer ID / win 证书视预算，首版可 unsigned + 手动安装引导）。
- 内核分发解耦：首版安装包**不带内核**（约 200MB），首次使用时 kernelManager 下载
  （已实现）或用户手动指定（已实现）；自建内核渠道接入 A2。
- 产物托管 GitHub Releases；自动更新（electron-updater）列 V0.5。
- 验收：干净虚拟机安装 → 跑通「注册 → 建环境 → 登录 → 存基线 → 重开免登录」全流程。

## 4. 生产硬化（服务端）

- 部署形态：docker compose（server + Postgres + 对象存储或托管 S3/R2）+ 反代 TLS（Caddy）；
  编写 `deploy/production.md`（密钥清单、环境变量、备份策略：Postgres pg_dump 定时 +
  存储桶版本化/复制）。
- 限流：auth 接口（注册/登录）IP+账号双维度；presign 接口配额。
- 可观测：结构化日志、/v1/health 增强（依赖探针）、审计查询只读 API。
- 快照配额：每用户存储总量上限（SNAPSHOT_RETENTION 之外的第二道闸）。

## 6. 风险

- Chromium 源码构建在本机（Intel Xeon）耗时 6–12h/次且磁盘 ~100GB → 一次性验证后续增量；
  或 fork 上游 GitHub Actions（免费额度 6h/任务，勉强够 Linux；mac runner 需付费或本机）。
- os_crypt 补丁侵入面小但随上游合并可能有冲突 → 锁定内核版本季度升级节奏。
- DBSC（Google 设备绑定会话）仍为行业硬限制，继续作为已知限制披露。
