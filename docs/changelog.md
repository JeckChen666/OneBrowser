## v0.4.3（2026-10-31）

- **团队协作（V0.6）**：每用户 X25519 身份密钥对 + 团队独立 DEK 成员信封。团队环境的配置与
  登录态用团队密钥端到端加密，服务端全程只见公钥与密文。邀请（push 模型，接受才激活）→
  成员免登录共享基线；吊销即时断云端访问；owner 可轮换团队密钥（旧基线冷启动，重存恢复）。
  团队 e2e 17 项全绿；运维工作台新增团队只读视图。
- **三承载**：指纹内核（防关联，每环境独立指纹）/ 标准浏览器（本机 Edge/Chrome 隔离窗口，
  免下载）/ 内置轻量（秒开）。
- **App 内检查更新**：关于弹层一键检查（真实 GitHub Releases 链路），有新版直达下载页。
- 品牌 logo（指纹涡纹 × 地球经纬）；快照模式「丢弃关闭」二次确认；环境详情抽屉；
  错误信息人性化。
